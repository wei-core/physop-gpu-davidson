# PhysOp GPU portable project

This repository extracts the validated GPAW packed-Gamma PhysOp path:

`E3 descriptor/H/S -> E4 two-inner GPU Davidson -> E5 live SCF seam`.

It is a clean package and has no runtime import from the historical V5R tree.

```bash
./scripts/bootstrap.sh
source .venv/bin/activate
python scripts/doctor.py
python scripts/smoke.py
python scripts/run_case.py --case SIC-008 --mode fixed5 --backend gpu
```

The GPU backend needs NVIDIA Driver API, NVRTC, cuBLAS, cuFFT and cuSOLVER.
The loader discovers them through the system dynamic loader and compiles kernels
for the active device's compute capability. Install GPAW PAW setup data and
export `GPAW_SETUP_PATH` before running a case.

The five supported geometry cases are SIC-008, SIC-032, SIC-064, SIC-128 and
SIC-216. Their dimensions are generated by GPAW at runtime from the geometry,
cutoff and bands policy; the reference dimensions are retained only as audit
metadata.
